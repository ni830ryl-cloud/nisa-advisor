# NISA成長投資枠 ファンド推奨ツール

NISA成長投資枠で長期投資を行うユーザーに対し、プロファイル分析とファンドのスコアリング結果を提供するツール。

> **免責事項**: 本ツールは投資助言ではなく、情報提供を目的とします。最終的な投資判断はご自身の責任で行ってください。

## 機能

- **プロファイル診断**: 投資経験・ホライズン・リスク耐性・地域選好を5問で把握
- **PF分析**: 既存保有ファンドの地域集中度・ギャップ・矛盾を検出
- **動的スコアリング**: プロファイルに応じて「何をリスクと見なすか」を変えて評価
- **方針提案**: PFギャップ補完・既存スタイル拡張・新領域挑戦の3方針

## クイックスタート

```bash
# 依存インストール
uv sync

# ローカル起動
uv run streamlit run src/ui/app.py
```

## 技術スタック

- Python 3.11+
- Streamlit（UI）
- pandas（データ処理）
- pydantic（モデル定義）
- rapidfuzz（ファンド名マッチング）

## プロジェクト構成

```
src/
├── models/     # データモデル（UserProfile, FundScore, ...）
├── core/       # スコアリング・フィルタ・PF分析ロジック
├── data/       # CSV読み込み・ファジーマッチング
├── ui/         # Streamlit画面
└── utils/      # 定数・ヘルパー
data/
└── fund_master.csv  # ファンドマスタ（30本、月次更新）
```
